1.项目概述

1.1 项目目标
    实现大学选课系统，实现选课流程自动化，管理数字化，保障选课准确性，在此基础上增加教学秘书排课的功能实现。

1.2 功能范围
    核心功能：学生选课/退课、课程查询、课表管理;老师登入成绩、选课名单输出;教学秘书排课

1.3 技术架构
    采用分层架构设计，各层职责清晰：
    表现层（Ui）：基于命令行实现可视化界面，负责用户交互与数据展示
    业务逻辑层（Control）：封装核心业务逻辑，处理选课，退课等流程的规则校验与执行。
    领域层（Domain）：定义实体类（Student,Course,Teacher等），封装数据属性与核心行为。
    数据管理层（Broker）：提供数据代管理，数据库连接，sql执行等基础服务。

2.模块设计

2.1 模块职责划分
    Broker：1.数据库连接池管理 2,数据代管理
    Control：1.选课/退课业务逻辑实现 2.教学秘书管理课程表和课程条目逻辑实现 3.教师登入成绩逻辑实现
    Domain：1.实体类定义 2.核心业务规则封装
    Ui：1.操作界面设计 2.用户交互逻辑实现

2.2 模块间交互流程
    1. 用户操作触发 Ui 层事件（如点击“选课”按钮）；
    2. Ui 层调用 Control 层对应接口，传递请求参数（学生ID、课程ID、老师ID、教学秘书ID）；
    3. Control 层调用 Domain 层实体类方法，执行规则校验；
    4. Control 层通过 Broker 层访问数据库，执行数据查询/更新操作；
    5. Broker 层返回操作结果，Control 层处理后反馈给 Ui 层；
    6. Ui 层展示结果。​

3.核心业务逻辑设计

3.1选课流程
    用户点击选课请求->Ui层调用Control层对应选课接口studentEnrollsInCourse->Control层接受请求->Broker层执行数据库操作->返回结果给Ui层

3.2退课流程
    用户点击退课请求->Ui层调用Control层对应退课接口studentDropCourse->Control层接受请求->Broker层执行数据库操作->返回结果给Ui层

3.3老师登入成绩
    用户点击登入成绩请求->Ui层调用Control层对应登入成绩接口teacherEnterGrade->Control层接受请求->Broker层执行数据库操作->返回结果给Ui层

3.4教学秘书创建/删除课程表/课程条目
    用户点击创建请求->Ui层调用Control层对应创建接口createSchedules/createSchedulesEntry/removeSchedules/removeScheduleEntrys
    ->Control层接受请求->Broker层执行数据库操作->返回结果给Ui层

3.5教学秘书加入/删除课程条目到课程表
    用户点击选课请求->Ui层调用Control层对应选课接口addEntrysToSchedule/removeEntrysToSchedule->Control层接受请求->Broker层执行数据库操作
    ->返回结果给Ui层

3.6教学秘书修改课程条目
    用户点击修改课程条目某个数据的请求->Ui层调用Control层对应接口modifyEntrytime/modifyEntryroom/modifyEntryteacher
    ->Control层接受请求->Broker层执行数据库操作->返回结果给Ui层
